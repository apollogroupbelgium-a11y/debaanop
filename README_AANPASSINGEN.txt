# De Baan Op - aangepaste versie

Aanpassingen in deze versie:
- Het totaal blijft 1000 vragen.
- De foto's worden met `object-fit: contain` getoond, zodat ze niet afgesneden worden.
- De vorige situatie-foto's blijven behouden, maar zijn vervangen door versies waarbij het bord/de situatie zichtbaar blijft.
- Nieuwe bordfoto's staan in `images/borden/`.
- Wanneer een vraag een herkenbare bordcode vermeldt, toont de site automatisch een passende bordfoto uit `images/borden/`, indien beschikbaar.
- Nieuwe extra foto's staan ook in `images/nieuwe-fotos/` zodat je ze kan controleren of later gebruiken.

Upload de volledige inhoud van deze map naar GitHub, inclusief:
- index.html
- functions/
- images/
- algemene-voorwaarden.html
- privacyverklaring.html
- cookieverklaring.html
