AANPASSING FOTO-WEERGAVE

In deze versie is de CSS aangepast zodat foto's niet meer worden afgesneden:
- geen vaste hoogte meer voor fotovragen
- geen object-fit: cover
- afbeeldingen gebruiken width: 100% en height: auto
- overflow staat zichtbaar in plaats van verborgen

Upload vooral index.html opnieuw. Als je ook foto's hebt gewijzigd, upload dan ook de map images.
