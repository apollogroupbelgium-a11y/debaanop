ONDERHOUDSMODUS / TESTTOEGANG

Deze versie staat standaard in onderhoudsmodus.

Gewone bezoekers zien alleen de melding dat De Baan Op wordt bijgewerkt.

Jij kan de echte website testen via:
https://debaanop.eu/?testtoegang=maxinelouis2026

Na het openen van die link wordt jouw browser als tester bewaard.

Website terug publiek zetten:
1. Open index.html in GitHub.
2. Zoek: const SITE_IN_ONDERHOUD=true;
3. Verander naar: const SITE_IN_ONDERHOUD=false;
4. Commit changes.

Deze versie bevat exact 1000 vragen: 975 gewone vragen + 25 fotovragen.
De 25 minst duidelijke tekstvragen zijn verwijderd.
